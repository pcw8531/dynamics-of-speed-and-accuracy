# Full model (formation, selective elimination, recruitment)

Run from the repository root:

    python3 code/sim_full.py sim_out
    python3 figures/fig5_full_model.py sim_out

sim_full.py writes sim_out/sim_full_result.txt and sim_out/sim_full_results.npz (about 2 minutes).
The figure script figures/fig5_full_model.py reads the npz and writes figures/fig5_full_model.png (Figure 5 of the manuscript).
Derivations: Supplemental Material, Section S3.2. Protocol: Section S5.3.
